# TEAM--08_OSSP

## Project

[ProcessPay — Linux Process Creation, Execution and Termination](PROJECT/README.md)
demonstrates real Linux processes through a payment workflow, with live PID/PPID,
OTP waiting, normal exit, signal termination and child reaping.

- [Live website](https://processpay-linux-lab-jashwanth.netlify.app)
- [Run the website locally](PROJECT/WEBSITE.md)
- [Project report](PROJECT/REPORT.md)

The deployed frontend uses a temporary connection to a Linux backend; payment
actions require that backend and its tunnel to remain running.
